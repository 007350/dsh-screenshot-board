# 0.2.0 代码复核

沿用原项目架构，按 code-review 检查正确性、错误路径、输入校验与数据保留，另安排只读复核。

已处理的问题：

- 保存期间打开交接又切板可能留下旧窗口：切板成功时关闭旧 dialog；交接入口保存前后核对板身份，导出绑定预览板；加入延迟保存/切板浏览器回归。
- <=900px 的旧样式隐藏全部项目背景入口：保留紧凑入口，并以真实无前文交接修改和 800px 操作验证。
- 独立预览没有聊天却显示收起到聊天：仅预览使用收起预览与恢复提示，DSH 默认文案仍保留。
- 旧上传测试在选择文件后未等待异步保存：等待实际 PUT 响应，避免把上一状态当失败。

关键约束：旧字段不重写；已验收默认参考；未确认、缺验收或缺复现的任务不得执行；空选择不回退全量；ZIP 用同一范围逻辑生成 Markdown 与结构化清单。背景快照显式声明不扩展执行范围。

保存冲突、备份恢复、图片限制与会话令牌沿用原有保护。普通 DOM 显隐不 dispose，关闭/卸载才清理。导出和文档均保留 DSH 实机未验证边界。完整证据见 VALIDATION.md。
